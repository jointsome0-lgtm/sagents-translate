# Проверки

- Держите тестовый набор минимальным. Не добавляйте тесты по умолчанию, ради процентов покрытия или по одному на каждую функцию.
- Сначала используйте существующие проверки и короткое ручное воспроизведение. Новый тест оправдан конкретным существенным риском или воспроизведённой ошибкой.
- Проверяйте наблюдаемое поведение и сохранность пользовательских данных. Не копируйте алгоритм реализации в тесты и не привязывайте их к внутренним структурам, разбиению на функции или порядку вспомогательных вызовов.
- Тесты должны позволять рефакторинг с сохранением внешнего поведения. Расширяйте подходящий существующий сценарий; убирайте избыточные и дублирующие проверки.
- Проверки перевода выполняйте через подставной backend и синтетические тексты. Реальные платные вызовы для проверки кода не нужны.
